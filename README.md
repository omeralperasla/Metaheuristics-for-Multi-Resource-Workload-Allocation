## Metaheuristics for Multi-Resource Workload Allocation

This is the single-script version for Option 2.

## Files

- Report.pdf contains the design rationale, experimental findings, figures and references.
- workload_optimisation.py contains the supplied loader, hill-climber, genetic algorithm, experiments and statistical analysis.
- The two original .txt datasets must remain beside the script.

Add the completed institutional Assessment Cover Sheet PDF separately.

## Run everything

Use Python 3.12. From the extracted folder, run:

```sh
python -m pip install numpy==2.3.5 scipy==1.17.0 matplotlib==3.10.8
python workload_optimisation.py
```

The script runs 30 baseline experiments and 30 paired challenge experiments. It uses fixed seeds and checks the resulting portfolios against every resource capacity. It generates CSV records, figures and a statistical summary locally. CSV files are not included in the submission package.

The report describes the included script's verified run. Runtime measurements can vary across machines. The PDF is static and is not regenerated by the experiment script.

Functions are grouped into the supplied data loader, Part 1, Part 2, experiments and statistical analysis. The supplied load_workload_instance function is included directly. All search logic and variation operators are implemented with NumPy. SciPy supplies statistical tests and a separate fractional upper bound.
